# Radix Sort

[Read the tutorial and try the visualiser](https://bigocast.com/learn/radix-sort).

Returns a new list and leaves the input unchanged. Accepts nonnegative integers and an integer base of at least 2. Memory grows with the selected base.

## Run

From the repository root:

```sh
python3 sorting/radix_sort/foundations/radix_sort.py
python3 -m unittest discover -s sorting/radix_sort/foundations -v
```

The example prints `[7, 12, 17, 24, 31, 42]`. Tests cover empty input, duplicates, reverse order and exhaustive small lists.

[More visual lessons on BigOCast](https://www.youtube.com/@bigocast).
