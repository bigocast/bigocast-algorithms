# Gnome Sort

[Read the tutorial and try the visualiser](https://bigocast.com/learn/gnome-sort).

Changes the supplied list and returns that same list.

## Run

From the repository root:

```sh
python3 sorting/gnome_sort/foundations/gnome_sort.py
python3 -m unittest discover -s sorting/gnome_sort/foundations -v
```

The example prints `[1, 2, 3, 4]`. Tests cover empty input, duplicates, reverse order and exhaustive small lists.

[Watch the BigOCast lesson](https://youtu.be/9cIjvXEeOhQ).
