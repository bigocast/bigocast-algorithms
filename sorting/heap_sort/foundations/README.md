# Heap Sort

[Read the tutorial and try the visualiser](https://bigocast.com/learn/heap-sort).

Changes the supplied list and returns that same list.

## Run

From the repository root:

```sh
python3 sorting/heap_sort/foundations/heap_sort.py
python3 -m unittest discover -s sorting/heap_sort/foundations -v
```

The example prints `[1, 2, 4, 5, 7, 9]`. Tests cover empty input, duplicates, reverse order and exhaustive small lists.

[Watch the BigOCast lesson](https://youtu.be/jtshKZDqeYo).
