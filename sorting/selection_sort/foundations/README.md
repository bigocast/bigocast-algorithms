# Selection Sort

[Read the tutorial and try the visualiser](https://bigocast.com/learn/selection-sort).

Changes the supplied list and returns that same list.

## Run

From the repository root:

```sh
python3 sorting/selection_sort/foundations/selection_sort.py
python3 -m unittest discover -s sorting/selection_sort/foundations -v
```

The example prints `[2, 3, 4, 5, 6]`. Tests cover empty input, duplicates, reverse order and exhaustive small lists.
