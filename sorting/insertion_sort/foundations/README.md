# Insertion Sort

[Read the tutorial and try the visualiser](https://bigocast.com/learn/insertion-sort).

Changes the supplied list and returns that same list.

## Run

From the repository root:

```sh
python3 sorting/insertion_sort/foundations/insertion_sort.py
python3 -m unittest discover -s sorting/insertion_sort/foundations -v
```

The example prints `[2, 3, 4, 5, 7]`. Tests cover empty input, duplicates, reverse order and exhaustive small lists.
