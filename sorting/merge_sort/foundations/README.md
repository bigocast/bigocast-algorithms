# Merge Sort

[Read the tutorial and try the visualiser](https://bigocast.com/learn/merge-sort).

Returns a new list and leaves the input unchanged.

## Run

From the repository root:

```sh
python3 sorting/merge_sort/foundations/merge_sort.py
python3 -m unittest discover -s sorting/merge_sort/foundations -v
```

The example prints `[1, 2, 3, 5, 6, 7]`. Tests cover empty input, duplicates, reverse order and exhaustive small lists.

[Watch the BigOCast lesson](https://youtu.be/gxdZubPijxQ).
